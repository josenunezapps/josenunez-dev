Agregar producto

Usá letras, números, guiones, barras, puntos o guion bajo. Si no tiene código, dejalo vacío.

Las fotos cargadas también quedan almacenadas solo en este dispositivo. Si la memoria local se llena, exportá una copia antes de hacer otros cambios.

Podrás agrupar productos dentro de este apartado. Se guarda solamente en este navegador.
EXCEL · CARGA MASIVA

Usá una planilla .xlsx para agregar o actualizar productos. Completá código, nombre, categoría, precio, descripción y una URL HTTPS de foto si la tenés. Las fotos actuales se conservan cuando dejás esa columna vacía.

FOTOGRAFÍAS

Elegí varias fotos llamadas, por ejemplo, PTA-001.jpg y VEN-002.png. Se asignarán a los productos que tengan esos códigos. Las fotos se guardan localmente en esta demo.

INFORMES Y RESPALDOS

El JSON permite restaurar productos y fotos guardadas localmente. El Excel es para editar y cargar productos; no incluye fotografías incrustadas.
